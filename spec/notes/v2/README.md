# v2 notes

**Status:** Holding area, non-normative. Nothing in this folder is v1 work, and
nothing here overrides a promoted spec.

This folder collects ideas and proposals for after v1: domain libraries such as
currency and dates and times, and anything else that should be written down now
but built later. A note here records the design and its open questions. When v2
planning starts, each note becomes a spec, an issue, or nothing.
